# C-log Android v0.2

Poprawiona wersja WebView. Lokalny HTML jest ładowany przez WebViewAssetLoader pod bezpiecznym adresem appassets, zamiast bezpośrednio przez file:///android_asset. JavaScript i DOM Storage są włączone.

Technologie: Java 17, AGP 9.3.0, Gradle 9.5.1, compileSdk 36, minSdk 26, AndroidX WebKit 1.17.1.

## UI v0.3

Domyślny motyw to czarne tło i biała czcionka. W Ustawieniach można przełączyć na białe tło i ciemną czcionkę. Układ interfejsu został dopasowany do zaakceptowanej makiety C-log.

## UI v0.4

Dodano zaakceptowaną zieloną ikonę aplikacji z napisem C-log. Ikona jest ustawiona jako ikona aplikacji Android.

## v0.5

Poprawiono ustawienie ikony aplikacji i wzmocniono uruchamianie JavaScript w WebView. Dodano diagnostykę błędów JavaScript.
